What is OpenClaw

OpenClaw is an open-source AI agent framework that connects large language models to your workflows, channels, and tools.

🤖

AI Agent Framework

Connect Claude, GPT, Gemini, and other LLMs to your daily workflows

💬

Multi-Channel Support

Real-Time Automation

Cron jobs, heartbeats, and event-driven workflows

🌐

Cross-Platform

Linux, macOS, Windows - deploy anywhere Node.js runs
