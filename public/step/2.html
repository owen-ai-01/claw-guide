Step 2: Core Installation

Install OpenClaw and complete the onboarding process.

What You'll Do

Install OpenClaw globally and complete the interactive onboarding.

Installation

npm install -g openclaw

Onboarding

After installation, run:

openclaw

The interactive onboarding will guide you through:

  • **Workspace Setup**: Choose a directory for your OpenClaw workspace
  • **Agent Configuration**: Create your first agent
  • **Model Selection**: Configure your preferred AI model (Claude, GPT, etc.)
  • **Basic Settings**: Set up initial preferences

    • Verification

    openclaw --help

    Expected output: OpenClaw help menu with available commands

    Pass Criteria

    ✅ `openclaw --help` runs successfully

    ✅ Workspace directory is created

    ✅ openclaw.json configuration file exists
